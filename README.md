# Prasun Kumar Biswas - Personal Engineering Portfolio

Welcome to my personal engineering portfolio! This project showcases my work bridging mechanical design, flight mechanics, and intelligent software systems.

## 🚀 Features & Walkthrough

### 1. Immersive 3D Hero Section
Upon landing on the page, you're greeted with a fully interactive 3D scene built with **React Three Fiber**.
- **Interactive Drone:** A 3D drone model accompanies you as you scroll down the page. It smoothly drifts across the screen, lingering to keep you company before flying off near the end.
- **Deep Space Environment:** The background features a dynamic, animated Starfield and Nebula. 
- **Asteroid Field:** The scene is densely populated with 300 floating asteroids, rendering efficiently via instanced meshes.

### 2. About Me
A concise overview of my philosophy: focusing on building from the ground up and integrating hardware with software. It highlights my core competencies in Aerospace, Hardware, and Software & AI.

### 3. Projects Showcase
An interactive grid of my top projects.
- **Filtering:** Quickly filter projects by category (Aerospace, Hardware, Software & AI).
- **Interactive Modals:** Clicking on any project card opens a detailed modal with images, technical challenges faced, and the outcomes achieved.
- **Tech Stack Tags:** Each project displays the specific technologies used.

### 4. Skills Arsenal
A responsive, organized grid displaying my technical skills across four categories:
- Hardware & Embedded
- Software Development
- Engineering Tools
- AI & Security

### 5. Contact Section
A fully functional contact form at the bottom of the page, allowing direct communication. It includes validation, success/error handling, and fallback direct email links.

## 🛠️ Technical Stack
- **Frontend Framework:** React + Vite
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **3D Graphics:** Three.js & React Three Fiber
- **Icons:** Lucide React & React Icons

## ⚙️ Running Locally
1. Clone the repository
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev`
